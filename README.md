# Para mi Tati ❤️

Página de cumpleaños (20 años · 25 de noviembre).

- Cuenta regresiva hasta las 00:00 (hora de Colombia), con travesuras y un mini juego mientras espera.
- Carta que se escribe sola, pastel con velas "2" y "0", constelación con el número 20.
- Números espejo (11:11, 20:20…).

## Probar sin esperar
- `…/#demo` → salta directo a la carta.
- `…/#espejo` → muestra un número espejo.

## Editar textos
Todo lo personalizable está en el objeto `CONFIG` al inicio del `<script>` en `index.html`.
